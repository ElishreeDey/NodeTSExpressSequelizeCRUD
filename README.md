# Node + TypeScript + Express + PostgreSQL + Sequelize CRUD

## Install Packages

npm install

## Update .env

Update:

- DB_HOST
- DB_PORT
- DB_USER
- DB_PASSWORD
- DB_NAME

## Run Development Server

npm run dev

## Build Project

npm run build

## Start Production Server

npm start

## API Endpoints

POST
http://localhost:3000/api/users

GET
http://localhost:3000/api/users
